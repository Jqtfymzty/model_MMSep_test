## 2. 正式实验结论

- 正式运行编号：`module2-formal-0bd7e93-001`
- 实验源代码：`0bd7e93`
- 指标修正提交：`65d3ea6`
- 15 条用例 × 2 种模式，共 30 个配置结果；无执行错误。
- 输出 Oracle 通过 26/30（86.67%）。
- 把性能阈值计入整条用例后，通过 11/15（73.33%）。
- 公平性和安全性全部通过；功能计数与低对比度计数存在稳定失败。
- MMSep 原型的 KV 估算减少 71.98%–72.98%，质量保持率为 1.00，但解码倍率仅 0.928×、0.948×，未达到 1.2×门槛。
- 最终验收结论：**不通过**。

## 3. 结果边界

本轮使用课程项目自建的 15 条确定性图文夹具，不是 ScienceQA、MMMU、`detail_2k` 或 `complex_reasoning_4k` 的论文基准复现。当前实现是视觉分隔符/KV 压缩原型，没有完整实现论文描述的文本分隔符维护和视觉召回。详细说明见 `docs/EXPERIMENT_SCOPE.md`。

## 4. 证据优先级

1. `raw/results.jsonl` 是不可变的逐次运行记录。
2. `summary/summary.corrected.json` 是修正性能口径后的正式摘要。
3. `summary/summary.json` 与 `manifest.json` 仅作为原始审计记录保留，不再作为性能结论依据。
4. `manifest.corrected.json` 保存本次证据的文件大小和 SHA-256。
