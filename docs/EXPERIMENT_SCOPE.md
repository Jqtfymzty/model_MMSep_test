# 模块二实验范围与实现边界

> 最后核对：2026-09-21

## 1. 本次正式实验实际覆盖范围

本项目的正式运行 `module2-formal-0bd7e93-001` 使用 15 条可自动生成、可离线复现的图文用例，覆盖功能、鲁棒性、公平性、安全性和性能。每条用例均以同一 LLaVA v1.5 7B 权重、相同量化方式、相同生成参数分别运行 Baseline 与 MMSep 模式；唯一实验变量是 `mmsep.enabled`。

这些用例是课程项目自建的确定性测试夹具，不是论文基准 `detail_2k`、`complex_reasoning_4k`、ScienceQA 或 MMMU 的样本。报告和演示不得把本轮结果表述为论文基准复现结果。

## 2. MMSep 实现边界

当前 `src/mmsep_runtime.py` 实现的是视觉分隔符/KV 缓存压缩原型：在指定 Transformer 层利用注意力分数保留部分视觉 token，并在后续层压缩视觉 KV。正式配置保留 106/576 个视觉 token，约为 18.4%。

论文方法还描述了文本分隔符维护、解码阶段缓存压缩以及分隔符触发的视觉召回。当前仓库没有完整实现这些机制，因此只能称为“受 MMSep 启发的视觉 KV 压缩原型”，不能声称完整复现论文。

## 4. 结果解释规则

- `26/30` 表示两个模式合计 30 个“用例×模式”配置中，26 个通过输出 Oracle，输出质量通过率为 86.67%。
- `11/15` 表示将性能阈值一并纳入后，11 条完整测试用例达到全部预设标准。
- 两条性能用例的输出质量和 KV 压缩率通过，但解码吞吐倍率分别为 0.928×、0.948×，低于 1.2×门槛，所以整条用例判为 NG。
- 上述结果只适用于本次固定模型快照、RTX 4090 环境和当前原型，不外推为论文方法的总体结论。
